# Changelog

## 0.3.0

- 單一 IP 黑名單可安全同步至 Home Assistant 原生 `ip_bans.yaml`。
- 新增待套用狀態與管理員確認的「套用並重啟 HA」按鈕。
- 只移除附加元件自行加入的封鎖，保留 HA 自動封鎖；CIDR 維持稽核用途。

## 0.2.0

- 新增介面內可調整的安全 IP 與黑名單，支援單一 IP 和 CIDR。
- 登入紀錄可一鍵加入名單，黑名單判定優先於安全名單。
- 名單保存在附加元件持久資料中，且只有 HA 管理員能修改。

## 0.1.2

- 移除公開原始碼中的站點專用安全 IP 預設值；已安裝站點的自訂選項不受影響。

## 0.1.1

- 將核心登入失敗日誌擷取間隔縮短為 15 秒，降低高日誌量時漏記的風險。

## 0.1.0

- 初版登入成功與失敗稽核介面。
- 支援安全 IP、管理員限定及失敗紀錄持久化。
